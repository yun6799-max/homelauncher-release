# 홈 런처 배포

안드로이드 홈 화면 정리 런처의 설치 파일(APK)을 올려 두는 곳입니다. 소스 코드는 비공개 저장소에 있습니다.

## 처음 설치
1. 폰에서 [최신 릴리스](https://github.com/yun6799-max/homelauncher-release/releases/latest)를 열고 `homelauncher-x.y.z.apk`를 받습니다.
2. "출처를 알 수 없는 앱 설치"를 묻으면 내려받은 앱(크롬 · 내 파일)에 허용합니다.
   삼성 폰에서 설치가 막히면 설정 → 보안 및 개인정보 보호 → **자동 차단**을 잠시 끄고 설치한 뒤 다시 켭니다.
3. 플레이 프로텍트 경고가 뜨면 "그래도 설치"를 누릅니다.
4. 홈 버튼을 누르고 **홈 런처**를 고릅니다. (설정 → 애플리케이션 → 기본 앱 → 홈 화면 앱에서도 바꿀 수 있습니다.)

## 업데이트
런처 설정 → **업데이트 확인** → 설치 버튼 한 번. 다시 깔 필요가 없고 배치·설정은 그대로 남습니다.
설치 전에 파일 지문(SHA-256)과 서명을 확인하고, 배치를 자동으로 백업합니다.
